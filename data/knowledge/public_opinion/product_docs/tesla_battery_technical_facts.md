# Tesla 2017–2023 Model 3 公共手册中的高压电池信息

公开资料事实整理 · 来源机构：Tesla · 适用市场：US。

## LFP 识别与充电限制

车主可在车机 Controls > Software > Additional Vehicle Information 查看高压电池类型。手册说明电池类型这一项仅在车辆使用 LFP（磷酸铁锂）时显示。不同电池可能有不同充电限制，LFP 车型应以车机 Controls > Charging 或手机应用提供的充电信息为准。
