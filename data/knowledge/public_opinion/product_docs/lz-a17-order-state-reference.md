# LZ-A17 订单状态与报价凭证

> synthetic · 砾舟智行 · LZ-PRC-2508 · LZ-A17 · 1.0。渠道运营组 · 虚构演练资料。
> 关联事件：订单价保调整。状态：authoritative。

## 状态映射

LOCKED 指用户已确认配置并锁单，BOOKED 指只预约未锁单，DELIVERED 指交车已签收。门店看板按最后一次状态变化显示当前阶段。

## 报价与权益

报价编号带渠道及版本。价格权益凭证随订单生成，锁单时间按订单服务的审计时间戳计算。展示价截图不能代替权益记录。

## 交付字段

车辆交付时间由交付订单的签收记录确认。修改预约时间不改变原锁单的报价凭证。
