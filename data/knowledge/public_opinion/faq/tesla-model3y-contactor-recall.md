# Tesla Model 3 / Model Y 电池包接触器召回车主答疑

公开资料事实整理 · 来源机构：Tesla · 适用市场：US。

## 涉及范围

企业支持页针对装有使用 InTiCa solenoid 的电池包接触器的部分 Model 3、Model Y。车主可用 Tesla 或 NHTSA 的 VIN 召回搜索确认是否涉及本车。

## 服务处理

Tesla 安排受影响车辆免费更换接触器。服务页面将此措施与其他车型或其他批次的电池包问题分开说明。
