# Public Opinion Report

Use the evidence and scope already available. Present the research question and time window, key findings, supporting sources, limitations, and suggested next steps.

Keep every substantive factual claim traceable to a source or clearly label it as an inference. Preserve disagreements and missing data. Include sentiment or risk measurements only when a supplied method and actual results support them.

Produce Markdown unless the user requests another format and an appropriate tool is available. Phase 0 has no migrated report generation pipeline; this skill supplies writing guidance and must not claim automated collection, analysis, export, or publication occurred.
